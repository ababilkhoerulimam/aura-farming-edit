# Runtime assets

Place optional edit assets in these locations:

- `assets/edits/reaction.mp4` — external meme/reaction clip
- `assets/sounds/pre_edit.wav` — sound played when an edit starts
- `assets/sounds/post_edit.wav` — sound played after the edit finishes

The application still runs when these files are missing. Missing video clips are replaced by a visible placeholder, and missing sounds are skipped.
